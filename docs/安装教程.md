# B860AV 机顶盒 → 家庭影院 KTV 点歌台 · 安装教程

> 目标：把吃灰的安卓机顶盒变成一台**家用 KTV 点歌台**——开机直进点歌大屏，本地 U 盘歌曲 + 在线搜歌，遥控器/鼠标/手机都能点歌。
> 本项目实机：**B860AV1.1-T2**（中兴微 ZX296716 / Android 4.4.2 / armv7）。**不刷机**，随时可还原。

---

## 0. 准备

- 盒子**已 root**，能开 **ADB** 或进 root shell（本机是开了 ADB over TCP）。
- 电脑/手机与盒子在**同一局域网**（在线点歌 + 手机点歌需要）。
- 需要的文件（都在本安装包里）：`ktv.apk`、`ktvnet.py`、`ktvnet-watch.sh`、`一键安装.sh`。

把整个安装目录拷到盒子，例如 `/sdcard/ktv-install/`。

---

## 1. 装点歌台 App

```sh
pm install -r /sdcard/ktv-install/ktv.apk
```

装好后它出现在应用列表里（名字「KTV点歌台」）。

## 2. 设为唯一桌面(HOME) → 开机直进

Android 4.4 **没有** `pm set-home-activity`，做法是**卸载旧桌面**，让本 App 成为默认桌面：

```sh
pm list packages | grep -i launcher      # 找到旧桌面包名(如 com.xxx.launcher)
pm uninstall <旧桌面包名>
```

> 旧桌面 apk 建议先备份：`cp /data/app/<包名>-*.apk /sdcard/desktop-backup.apk`，方便回滚。

## 3. 部署在线点歌后端（Linux 子系统 / chroot）

在线点歌（网易云）由盒子上的一个小服务提供，App 通过它访问网络（避开 Android 4.4 直连 HTTPS 的老问题）。

```sh
R=/data/linux                       # 你的子系统(chroot)路径
cp ktvnet.py        $R/root/ktvnet.py
cp ktvnet-watch.sh  $R/root/ktvnet-watch.sh
chmod +x            $R/root/ktvnet-watch.sh
```

在盒子**开机脚本**里拉起守护（示例，`/data/startlinux.sh`）：

```sh
chroot $R /sbin/start-stop-daemon --start --background --make-pidfile \
  --pidfile /run/ktvnet.pid --exec /bin/sh -- /root/ktvnet-watch.sh 2>/dev/null
```

> ⚠️ **关键坑**：开机由 `start-stop-daemon` 拉起时 **PATH 不含 `/usr/bin`** → 脚本里必须用**绝对路径 `/usr/bin/python3`**，否则报 `nohup: can't execute 'python3'` 静默失败（守护脚本 `ktvnet-watch.sh` 里已经这么写了）。

## 4. 开机兜底（可选，推荐）

有些 ROM 开机画面偶尔不消失会挡住桌面。若有类似 `/data/bootfix.sh` 的兜底脚本，把里面的桌面包名改成：

```
com.openhardwarelab.ktv
```

## 5. 重启

重启后应**直接进入 KTV 点歌台**（默认在「在线点歌」，显示热歌榜）。

---

## 6. 放歌 / 放电影

- **内部存储**：`/sdcard/ktv/`
- **U 盘**：任意位置（App 会读系统挂载表自动识别可移动盘；**插上/拔下自动重扫**），也认 `ktv` 子目录。
- **命名**：`编号-歌名-歌手.mp4`；伴奏/原唱分别加 `-伴奏` / `-原唱`（同编号自动合成一首、播放中可切）；同名 `.lrc` 自动当歌词。
- **电影/视频**：U 盘里的视频也会出现在「本地曲库」，点开全屏播放。

## 7. 操作

| 遥控器/键盘 | 作用 |
|---|---|
| ↑ ↓ | 在「顶栏 / 快捷按钮行 / 曲库 / 已点」之间上下移动 |
| ← → | 行内选择（切模式 / 选 热门·戏曲·儿歌·歌手 / 曲库⇄已点） |
| 确定 | 进入 / 点歌 / 播放 |
| 数字·字母 | 搜索 |
| 删除 | 退格 |
| 返回 | 清空搜索 / 回上级 |
| 菜单 | 本地=重扫曲库 |

播放中：确定=暂停 · ←=重唱 · →=切歌 · ↑↓=音量 · 菜单=原唱/伴奏 · 返回=回点歌台。**鼠标点击**也能点歌/切页签。**可拖动进度条**在屏幕中下部。

## 8. 手机扫码点歌

首页**右下角二维码**——手机（同一 WiFi）扫一下，用浏览器打开即可**点歌**：本地曲库 / 在线点歌 切换、搜歌、点歌（点了就在盒子大屏播），底部看「正在播放 / 已点 N 首」。

## 9. 还原

- 卸载 App：`pm uninstall com.openhardwarelab.ktv`
- 装回旧桌面：`pm install /sdcard/desktop-backup.apk`
- 还原开机脚本里加的那行 ktvnet 自启。
