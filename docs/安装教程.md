# 安装教程（标准版 v2.0）

## 前置条件
- 机顶盒已 **root**（有 `adb root` 或串口 shell）
- Android 4.4+，armv7（armeabi-v7a）
- 若要在线点歌：需要能装 armhf Linux chroot 的空间（`/data` 至少 400MB）

## 一、adb 方式（最快）
1. 盒子开网络 adb（本版本会写入 `persist.adb.tcp.port=5555`，重启后自动开）
2. 电脑：`adb connect <盒子IP>:5555` → `adb devices` 看到 device
3. `./install/一键安装.sh` （或 `./install/一键安装.sh <盒子IP>:5555`）
4. 盒子自动重启 → 直接进 KTV 点歌台

## 二、装在线点歌（可选）
```bash
# 在盒子 root shell 里
wget http://<你的服务器>/ubuntu-base-20.04.5-base-armhf.tar.gz -O /data/base.tgz
mkdir -p /data/linux && tar xzf /data/base.tgz -C /data/linux
# 换源 + DNS（国内环境）
cat > /data/linux/etc/apt/sources.list <<'S'
deb http://mirrors.tuna.tsinghua.edu.cn/ubuntu-ports/ focal main universe
S
echo 'nameserver 223.5.5.5' > /data/linux/etc/resolv.conf
# 关键：Android 的 paranoid network 让 _apt 无法建 socket
chroot /data/linux /bin/bash -c "apt-get -o APT::Sandbox::User=root -o Acquire::ForceIPv4=true update && apt-get -o APT::Sandbox::User=root install -y python3"
# 复制代理并启动
cp install/ktvnet.py /data/linux/root/
sh /data/ktvstart.sh
```
（若时钟是 1970 年，先 `date -s "2026-01-01 00:00:00"`，否则 apt 报 Release 文件"未生效"）

## 三、验证
- 电视：开机即进点歌台，右下角二维码
- 手机：扫码 → 搜索 → 点歌 → 「已点」→ 切歌
- 本地：U 盘插上，命名 `001-歌名-歌手.mp4`，按菜单键重扫
