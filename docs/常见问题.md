# 常见问题（FAQ）

**Q：开机没进点歌台 / 还是原来的桌面？**
A：本 App 需成为**唯一 HOME**。Android 4.4 没有 `pm set-home-activity`，请**卸载旧桌面**（`pm uninstall <旧桌面包名>`）后重启；或让开机兜底脚本 `am start -n com.openhardwarelab.ktv/.MainActivity`。

**Q：在线点歌没结果 / 一直空？**
A：① 盒子要**联网**；② 在线后端 `ktvnet.py` 要在跑——在盒子子系统里 `python3 -c "import urllib.request;print(urllib.request.urlopen('http://127.0.0.1:8089/ping').read())"` 应返回 `b'ok'`；③ 若刚开机瞬间为空，App 会每 3s 自动重试（最多 8 次）。

**Q：在线后端起不来？**
A：多半是 **PATH 坑**——开机 `start-stop-daemon` 拉起时 PATH 不含 `/usr/bin`。守护脚本里请用**绝对路径** `/usr/bin/python3`（随包的 `ktvnet-watch.sh` 已处理好）。

**Q：本地曲库看不到 U 盘里的歌？**
A：App 会读 `/proc/mounts` 自动找可移动盘，**插拔会自动重扫**；也可按**菜单键**手动重扫。若还看不到，确认 U 盘已被系统挂载（`cat /proc/mounts | grep -i vfat`）。

**Q：播放在线歌时黑屏？**
A：不会——**音频播放时显示动态粒子动画**。若真黑屏，检查 App 是否最新版本。

**Q：没有声音？**
A：先看系统媒体音量——`dumpsys audio` 里 **STREAM_MUSIC** 当前输出设备的音量（`settings` 显示的不一定准）。App 有保底：播放时若音量 ≤2 会自动调到约 2/3。若调满仍无声，多半是**输出通道**问题（HDMI / AV），在盒子的声音设置里切换输出。

**Q：手机扫码点歌打不开？**
A：手机要和盒子**同一 WiFi**；二维码内容形如 `http://<盒子IP>:8081/`。盒子 IP 变过的话，重启 App/盒子会重新生成二维码。

**Q：能放电影吗？**
A：能。U 盘里的视频（mp4/mkv/avi/ts/mov/flv/wmv/rmvb…）会出现在**本地曲库**里，点开全屏播放。

**Q：想还原成原来的桌面？**
A：`pm uninstall com.openhardwarelab.ktv` 后 `pm install /sdcard/desktop-backup.apk`，并去掉开机脚本里加的 ktvnet 自启行。
