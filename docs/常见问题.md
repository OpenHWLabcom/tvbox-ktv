# 常见问题

**Q: 提示 INSTALL_FAILED_NOT_SUPPORT**
运营商 ROM 禁用第三方安装。用 root 直接替换 `/system/app/KTV.apk`（本包的一键脚本就是这么做的）。

**Q: 换完 APK 后黑屏 / 点歌页打不开 / 手机连不上 8081**
没有重启。Android 需要重启才会重建 dalvik 缓存，否则 `ClassNotFoundException`。

**Q: 在线点歌搜不到 / 一直"正在搜索"**
1. 盒子是否联网（`ping 223.5.5.5`）
2. `/data/linux` chroot 是否装好、`python3` 是否存在
3. 代理是否在跑：`busybox netstat -tln | grep 8089`
4. 重启后看 `/data/ktvnet.log`

**Q: 点了歌没声音，或者播放器一闪而过**
多半是 URL 走了 **https**（Android 4.4 老 OpenSSL 握手失败）。本版已改为全部 http + App 自己跟随 302；若自己改代码请保持。

**Q: 手机扫码后打不开网页**
- 手机和盒子必须同一局域网；路由器若开 **AP 隔离** 会不通
- 二维码太小会扫出残缺 URL，本版已放大到 220dp 并在下方印出地址，可直接手输

**Q: 为什么有的歌搜不到/不能播**
在线只取**各平台免费可播**曲目；会员/VIP 曲（如多数热门歌手全集）拿不到版权直链，属正常。

**Q: 怎么恢复原来的桌面**
把 `/system/app_disabled/` 里的 launcher 移回 `/system/app/`，删掉 `/system/app/KTV.apk`，重启。
